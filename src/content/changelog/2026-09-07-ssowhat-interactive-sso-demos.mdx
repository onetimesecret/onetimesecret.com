[SSO What](https://ssowhat.dev) is a collection of interactive demonstrations for
understanding authentication and enterprise SSO flows.

Each walkthrough shows how  as the example application, covering social login,
enterprise identity providers, SAML logout, SCIM provisioning, protocol bridging, and
home-realm discovery.

NOTE: it's an educational tool, not a production service. It is not intended for use with real credentials or sensitive data.
