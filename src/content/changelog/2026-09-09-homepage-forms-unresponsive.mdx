The incident began at 21:47 UTC on 8 September and lasted about three hours. The homepage
remained visible, but the Create Link form, region selector, and pricing controls did not
respond. Regional apps where secrets are created and read remained available, and no secret,
account, or submitted data was affected.

We found that our deployment process could use untested dependency versions when its build
tooling fell out of sync with the project. This allowed a bundle that could not start the
page's interactive components to be published. A classic "works in development but not in
production" problem.

We have aligned deployment configuration with the project so release builds use the same
dependency versions as the builds that passed CI. We also expanded browser coverage of
interactive pages to catch similar failures before deployment.
